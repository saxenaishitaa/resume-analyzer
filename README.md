# 🚀 ATS Resume Analyzer

A smart web-based tool that analyzes resumes based on job roles and provides keyword-based scoring and suggestions.

## 🔥 Features
- 📄 Paste resume and analyze instantly  
- 🎯 Role-based analysis (Frontend, Backend, Java)  
- 📊 Resume score with percentage  
- 📉 Progress bar visualization  
- ✅ Strong & ❌ Missing keyword suggestions  
- 💡 Final verdict (Strong / Average / Needs Improvement)  

## 🛠 Tech Stack
- HTML  
- CSS  
- JavaScript

## 💡 How It Works
- User pastes resume  
- Selects job role  
- System checks for relevant keywords  
- Generates score + suggestions
